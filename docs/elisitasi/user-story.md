# Catatan Wawancara — Simulasi Persona 1

> **Latihan simulasi:** Persona dan catatan berikut bersifat fiktif untuk latihan analisis, bukan informasi hasil wawancara atau fakta tentang klien sebenarnya.

## Catatan simulasi

Persona 1 adalah pengelola dokumentasi resep dalam sebuah kelompok pelestarian resep daerah.

- “Saya mencatat bahan dan langkah resep di buku; kadang ada resep baru yang dikirim lewat chat.”
- “Kalau diminta mencari resep lama, saya perlu membuka beberapa halaman dan kadang lupa resep itu tersimpan di mana.”
- “Saya ingin semua resep dikumpulkan di satu website yang bisa dicari.”
- “Kalau ada koreksi takaran, saya biasanya bertanya kepada pembuat resep lewat chat. Perubahannya tidak selalu ikut tercatat di buku.”
- “Foto hasil masakan tersimpan di ponsel dan kadang sulit dicocokkan dengan resepnya.”
- “Akan bagus kalau website-nya bisa menghitung ulang takaran secara otomatis.”

## Analisis
